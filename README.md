# Email Spam Detection with Machine Learning

# Objective
Build a machine learning model to classify emails as
spam or non-spam (ham).

# Approach
- Cleaned and prepared text data
- Converted email text using TF-IDF vectorization
- Trained a Naive Bayes classifier
- Evaluated performance using accuracy and classification report

# Conclusion
The model successfully identifies spam emails and can help
protect users from phishing and scam messages.
